# Execution Plan Directory

Create one living execution plan per complex feature or implementation phase.

Use the structure defined in `../../.agent/PLANS.md`.

Naming examples:

- `phase-0-repository-foundation.md`
- `phase-1-supabase-foundation.md`
- `request-creation-workflow.md`
- `openai-agent-orchestration.md`

Do not use this directory as a general task list. A plan should describe a complete, testable outcome and remain updated while work is performed.
