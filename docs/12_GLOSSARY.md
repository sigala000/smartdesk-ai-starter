# Glossary

## Agent

The OpenAI-powered conversational component that interprets customer messages and requests approved tools. It is not the complete application.

## Application service

Server-side business logic that enforces rules and coordinates data operations.

## Assignment

The current or historical link between a request and a department or employee.

## Attachment

A privately stored file associated with a conversation or request.

## Audit event

An append-only record of an important business or administrative action.

## Confirmed field

A structured value that the customer has reviewed or explicitly corrected.

## Conversation

The message thread between a customer, the virtual assistant, and possibly employees.

## Customer-safe update

A status explanation approved for customer display. It excludes internal notes.

## Draft

Structured request information collected before final customer confirmation.

## Handoff

The transfer or escalation of a conversation to an employee.

## Idempotency key

A unique value used to make repeated submission attempts return the same result instead of creating duplicates.

## Knowledge document

Approved organization content that may ground customer answers.

## Organization

A company tenant using SmartDesk AI.

## Organization member

An authenticated employee linked to an organization and role.

## Reference number

A human-readable request identifier generated by the backend. It is not a secret or authentication factor.

## Request

A structured customer need that the company can assign, track, and close.

## Responses API

The OpenAI API interface used by the server to obtain model responses and tool requests.

## Row Level Security

Database policies that restrict rows according to user and organization context.

## Service

An offering configured by an organization, such as renovation or plumbing.

## Tool

A narrowly defined action the model may request. The server validates and executes it.

## Tenant

An organization whose data must remain isolated from all other organizations.

## Tool result

Structured output from a server-executed action. The assistant may report success only when the result confirms it.

## Verification token

A short-lived credential proving that a customer passed the status lookup challenge.
# Phase 10 terms

- **Developer-test recipient:** A phone number separately authorized in Meta's
  test environment and also enabled in SmartDesk's bounded server-side allowlist.
- **Embedded Signup:** Meta's official authorization flow through which a client
  company selects or creates its own WABA and phone-number asset.
- **Meta billing:** Charges and payment configuration between Meta and the client
  company. SmartDesk does not collect the card or share a credit line.
- **SmartDesk subscription:** The separate trial, plan, seat, usage, grace, and
  suspension state for access to SmartDesk.
- **WABA:** WhatsApp Business Account. A WABA may contain multiple phone numbers,
  but it cannot be claimed by two SmartDesk tenants.
- **Round-trip activation:** Promotion from `test_pending` to `active` only after
  an authenticated inbound webhook and a successful outbound provider response.
