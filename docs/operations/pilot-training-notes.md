# Pilot Training Notes

## Administrator

Create employees through the approved Supabase Auth/admin process, then add exactly one active organization membership with the minimum role. Deactivation is preferred to deleting audit history. Review queues, backups, alerts, access, and retention on the agreed schedule.

## Employees

- Verify the tenant/account displayed after login; never share accounts.
- Assign only within BuildPro, use valid status transitions, and record internal context in internal notes—not customer messages.
- Internal notes never appear to customers. Employee messages in an active handoff do.
- Accept a handoff before saying you joined; resolve it explicitly before automation resumes.
- Never invent a price, deadline, guarantee, reference, or successful action.
- Treat attachments as untrusted and report suspicious files.
- Use a trace ID when reporting errors, but never copy customer messages, tokens, keys, cookies, or verification codes into tickets.

Training completion requires supervised customer/request/handoff/status exercises and acknowledgement of the known limitations.
